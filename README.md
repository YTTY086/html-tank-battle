# 坦克大战 · Battle City

一个使用纯 HTML5 Canvas 编写的经典坦克大战（Battle City）网页游戏，单文件实现，无需任何依赖或构建步骤，双击 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，**消灭所有敌军坦克**并**保卫基地**（老鹰）。
- 击毁砖墙开辟通道，钢墙不可摧毁。
- 基地或你的全部坦克被毁，则游戏结束。
- 每过一关敌军数量会增多，得分与关卡实时显示。

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | 方向键 / `W` `A` `S` `D` | 屏幕虚拟方向键 |
| 射击 | 空格 / `J` / `F` / `回车` | 开火按钮 |
| 暂停 | `P` / `Esc` | — |
| 结束对局 | `E` | — |

## 运行

直接用浏览器打开 `index.html` 即可，或将目录部署到任意静态服务器（如 GitHub Pages）。

## 技术特点

- 纯原生 JavaScript + Canvas，零依赖
- 基于 26×26 半格网格的碰撞检测（13×13 地图）
- 敌人 AI：自动寻路 + 随机转向 + 定时射击
- Web Audio API 生成音效（无外部音频资源）
- 粒子爆炸特效、屏幕震动、无敌帧闪烁
- 响应式布局 + 移动端触屏控制
